Agent Builder (Beyond Prompt and Pray)
======================================

single ``NN_capstone`` notebook that adds that chapter's layer to the running banking
complaint agent. Rendered as saved; run them locally (they import :mod:`forgeloop.agents`) to
regenerate outputs.
