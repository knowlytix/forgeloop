User Guide
==========

forgeloop is one installable library spanning the companion code for the three
*Beyond … and Pray* books. It is organized into three parts, one per book:
building governed agents, testing agentic systems by design, and governed
retrieval over geometric memory. The three share a common substrate — the
pattern in which a language model proposes a structured action and a geometric
model store approves or rejects it against a calibrated operating point.

This guide introduces each part at the level of concepts and entry points. The
:doc:`API reference </3-api-reference/modules>` documents every public class and
function, and the :doc:`examples </examples>` show the entry points in use.
