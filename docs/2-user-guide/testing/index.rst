Testing
=======

This part follows *Beyond Ship and Pray*, one page per chapter and in the book's
order. It develops testing agentic systems by design of experiments: why average
accuracy is not enough, the geometric memory that supplies ground truth, the
base and factor catalogs, experimental design and composition, training-data
generation, logistic attribution of failure, resilience under tool faults, and a
capstone that tests a governed agent end to end. The pages correspond to
:mod:`forgeloop.testing` and :mod:`forgeloop.agents.testing`.
