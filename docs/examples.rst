Examples
========

The runnable chapter notebooks from the three books, grouped by book. Each
notebook is rendered in full — markdown, code and any saved outputs. Execution
is off at build time, so a notebook that was not run before rendering shows its
code without output; run it locally to regenerate outputs (the agent and testing
notebooks import :mod:`forgeloop`; the RAG notebooks also need the licensed GMS
backend).
