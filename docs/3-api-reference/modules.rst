API Reference
=============

The API used across the three books, organized by book. Each subpackage is
an index of one page per module, so every page is short and the granularity
is uniform. ``forgeloop.rag`` and ``forgeloop.testing`` are thin wrappers over
the licensed ``knowlytix`` backend, whose modules are grouped beneath the book
that uses them; a final group holds the shared geometric substrate.
